Strings in C

A beginner's personal guide — from "wait, no ampersand?" to actually getting it.

A Akriti Singh · 1st Semester BCA student
AUTHOR'S NOTE

I'm sharing my actual learning notes from the past lab sessions. When I started C, storing numbers was pretty basic and simple, but strings were very different — genuinely difficult to wrap my head around at first. Here's what I learned, in the order it finally clicked.

01

From numbers to words

In the initial lectures of C programming, everything was about integers and floats — calculating average marks, checking passing grades with conditional statements. Then my professor introduced strings and their functions. That's when I realized: there's more to it.

A string is essentially a sequence of characters — letters, symbols, or numbers — treated as a single unit of text. Words like "AKRITI" or "BENGALURU" are strings. But behind the scenes, C stores them using an array of type char.

02

What is a string in C, really?

A string in C is just a character array, where each character sits in its own slot and the array is terminated by a special marker. For instance, when we declare:

notes.c
char arr[] = "Akriti";

Here's how C actually stores it inside the computer's memory cells:

A
[0]
K
[1]
R
[2]
I
[3]
T
[4]
I
[5]
\0
[6]

Character → array index, one memory cell at a time.

03

The twist: the null character (\0)

Notice that extra slot at index [6] holding \0 — the null character. This was the single most confusing thing for me when I first saw it.

Because C character arrays don't automatically keep track of their own size, C uses \0 as a stop signal that tells the compiler where the string ends. Without it, your program keeps reading random garbage memory past your actual text.

Did you know?

A word with 6 letters (like "AKRITI") actually needs 7 memory slots in C. Always allocate 1 extra space for the hidden \0 byte, or your program gives garbage output.

04

Declaring and initializing strings

You can declare a string in two simple ways:

notes.c
char name[20];
char name[] = "BCA Student";
DeclarationMeaning
char name[20]; Reserves space for up to 19 characters + 1 null character.
char name[] = "BCA Student"; Automatically calculates size (11 chars + 1 = 12 bytes).

05

Taking string input

One common beginner trip-up: a string stored in a character array is read differently from a normal integer variable.

notes.c
scanf("%s", firstName);

no & here — trust me, I checked three times

We wrote scanf("%s", firstName); without an ampersand (&). That's because an array name itself already acts as a memory address. Adding & is a habit from integers that beginners often repeat here by accident.

A small memory reminder

For a beginner, the easiest way to remember strings is: characters are stored one after another, and \0 marks where the string ends.

06

Handy functions in <string.h>

Instead of manually counting characters with loops, C gives us standard built-in functions inside the #include <string.h> header:

FunctionSyntaxPurpose / return value
strlen() strlen(string); Finds the length of a string.
strcpy() strcpy(destination, source); Copies the source string to destination.
strncpy() strncpy(destination, source, n); Copies up to n characters.
strcat() strcat(string1, string2); Joins / appends string2 to string1.
strncat() strncat(string1, string2, n); Joins up to n characters of string2.
strcmp() strcmp(string1, string2); Compares two strings.
0 Both strings are equal
< 0 s1 comes before s2
> 0 s1 comes after s2
strncmp() strncmp(string1, string2, n); Compares the first n characters.

These functions save time and make code far more compact than hand-rolled loops.

07

Real-life connection: a student registration system

Almost every real application — from college web portals to login forms — uses strings. A student's name, city, category and other text-based details are all data that can be stored as strings.

A simple registration-style program can use character arrays for details like a student's name and city:

register.c
#include <stdio.h>

int main() {
    char studentName[30], city[20];
}

Why strings matter in C

Numbers let programs calculate. Strings let our C code actually interact and talk with human users. That's why understanding character arrays is worth the initial confusion.

08

Top 3 mistakes I used to make

These are the mistakes I personally keep in mind while writing a string program in an exam:

MistakeWhat happensWhat to remember
Comparing strings using == if(str1 == str2) compares memory addresses, not words. Use strcmp()
Missing header Forgetting #include <string.h> when using strlen() or strcpy(). Include <string.h>
Array overflow Storing a 25-letter word inside a char name[10] variable. Size it generously

09

Conclusion

Switching from numbers to strings felt like a jump at first. But understanding that a string is just a character array ending with \0 made everything click for me. Numbers let programs calculate — strings let our C code actually talk to the humans using it.

My key takeaways

  • A string in C is stored using a character array.
  • Every string needs a null character (\0) at the end.
  • The <string.h> header provides useful string functions.
  • String comparison should be done using strcmp(), not ==.
  • Enough array space should always be provided to avoid overflow.
